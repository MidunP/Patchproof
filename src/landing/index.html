The Engineering Guarantee

Enforced in code.
Not in documentation.

Generic coding agents generate plausible-looking pull requests that fail silently in production. Patchproof enforces five uncompromising invariants directly in the pipeline gate.

INVARIANT 01 Pre-Fix Gate

Deterministic Failure First

The reproduction test must fail against the unpatched codebase with a clean assertion failure. Syntax errors, missing imports, or runtime crashes abort the run immediately.

AssertionError: expected false to be true
INVARIANT 02 Cryptographic Security

SHA-256 Digest Lock

The reproduction test file hash is locked prior to patch synthesis. If an agent attempts to delete assertions, comment out tests, or weaken constraints, the run terminates.

sha256(testFile) === preExecutionDigest
INVARIANT 03 Post-Fix Gate

Clean Reproduction Pass

Once the minimal patch is applied, the reproduction test is executed again in the air-gapped sandbox. It must complete with zero failures and at least one executed assertion.

Tests: 1 passed, 1 total (100% pass)
INVARIANT 04 Regression Guard

Full Suite Zero-Regression

Every pre-existing test in the target repository is executed against the patched tree. A single regression in any existing test file immediately blocks the pull request.

fullSuite.failed === 0 && regressions.length === 0
INVARIANT 05 Causality Gate

Causal Stash Differential

The verification gate stashes the patch and executes the reproduction test against the bare base tree once more. It must fail again, proving the patch is the sole cause of the fix.

git.stash() -> runRepro() must fail

Privacy Policy

Last Updated: October 2026

1. Code Processing & Isolation

Patchproof clones source code repositories exclusively into ephemeral, air-gapped Docker containers. Once dependency installation completes, network interfaces are permanently detached. Your repository code is never shared, sent to third-party telemetry, or retained beyond the lifecycle of the active run.

2. Secret Scrubbing

All tool execution logs and compiler diagnostics pass through automated entropy and pattern-based secret redaction before emission over Server-Sent Events or storage in PostgreSQL. GitHub tokens, API keys, and environment variables are stripped by default.

3. Telemetry Retention

Execution metadata, step timings, and verification hashes are stored locally in your database instance. No data leaves your infrastructure.

Sandbox Security Specification

Security Standard: Rev 2.4

1. Air-Gapped Network Policy

Docker containers start with outbound network strictly during git clone and package manager dependency resolution. Prior to LLM tool execution, Docker API NetworkDisabled: true is committed. No egress packets are permitted.

2. Path Traversal & Forbidden Paths

The agent tool layer rejects attempts to read or write to .git, .github, .env, or paths containing traversal tokens (../).

3. Tamper Resistance

The reproduction test file hash is computed with SHA-256 immediately after pre-fix failure is confirmed. The gate aborts if the digest deviates during verification.
